2. **Tony Robbins removed.** No real person's likeness in the frame. The second seat is a generated interviewer, so nothing is tied to a living public figure.
3. **Only one identity is locked** — Lior's, from the reference photo. She is generated fresh, described in enough detail to be reproducible.
4. **Vertical added.** 9:16 with headroom for the question card at the top and subtitle safe area at the bottom.
5. **Negative prompt block added** — the AI tells that kill realism.
6. **Consistency note:** generate her once, save that frame as a character reference, reuse it for all 7 episodes. Same woman, same chair, same light every time. That repetition is what makes it a series.
