### How to measure v1 vs v2

LinkedIn has no A/B test for headlines, so compare before and after.
- Main metric: followers gained divided by profile viewers, per week. Use a ratio, because one big post inflates raw counts.
- Secondary: search appearances, and the acceptance rate on outbound connection requests.
- Compare the 14 days before 2026-11-09 with the 14 days after. Change nothing else on the profile while the test runs.
