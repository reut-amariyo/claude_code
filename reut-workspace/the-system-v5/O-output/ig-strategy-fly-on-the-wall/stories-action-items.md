## Phase 5: Engagement & Growth Tactics via Stories

### "DM Me" Triggers (2-3x/week)
- [ ] Week 1: "DM me STACK and I'll send you the 5 AI tools I actually use"
- [ ] Week 2: "DM me CEO and I'll share what my actual morning routine looks like"
- [ ] Week 3: "DM me HIRE and I'll tell you the one question I ask every candidate"
- [ ] Build an auto-response in Instagram (or use ManyChat) so DM keyword triggers an auto-reply with the content. This scales.
- [ ] Track: how many DMs per trigger? Which keyword works best?

### "Answer in Stories" (2x/week)
- [ ] Pick 1 interesting DM per day (can be a question, a compliment, a pushback)
- [ ] Screenshot it (blur name)
- [ ] Post to Story with Lior's answer (text or video response)
- [ ] The message to followers: "Lior actually reads and responds to DMs" → more people DM → algorithm boost

### "Close Friends" Tease (1x/week)
- [ ] Post something slightly more personal/raw to Close Friends list
- [ ] Then post a regular Story: "Just shared something on Close Friends I can't post publicly here. DM me 'IN' to join."
- [ ] Add people who DM to Close Friends
- [ ] This builds an inner circle and drives DM volume

### Story Polls That Feed Reel Ideas
- [ ] When a poll gets 500+ votes → that topic is a Reel
- [ ] When a Q&A question gets asked 3+ times → that's a Reel
- [ ] Track this in the content bank: "Stories that should become Reels"

### Monthly Review Questions
1. Which Story TYPE gets the most views? (Double down on it)
2. Which Story TYPE gets the most replies? (This drives algorithm)
3. Are DMs increasing week over week? (If not, add more "DM me" triggers)
4. Is Lior sending raw captures consistently? (If not, simplify his routine)
5. Are poll topics generating Reel ideas? (Track the funnel)
6. Completion rate trend — are people watching more or fewer Stories? (If dropping, reduce volume per session, spread across the day better)

### Kill Rules (Stop Doing These If They Don't Work After 3 Weeks)
- If quizzes consistently get <100 interactions → stop quizzes, use polls instead
- If Q&A boxes get <10 questions → reduce to 1x/week, try different prompts
- If Close Friends tease generates <5 DMs → stop, focus on regular DM triggers
- If Screenshot Stories get <50% of Fly on the Wall views → reduce to 1x/week
