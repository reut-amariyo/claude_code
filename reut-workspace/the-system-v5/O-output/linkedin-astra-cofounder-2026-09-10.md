saved, and none of it is executable from the post. The video's real line is at 0:30: "it feels like I'm talking to

an interview saved as files, and a map file it reads before every message. Three steps, no kit.

For the first two years at AutoDS there was no co-founder. Every developer, every supplier, every new hire got the whole story from the start, from me, again. Michael joined in 2018 and the explaining stopped. That is the actual job of a co-founder.

3. Create a file named AGENTS.md at the top of the folder. Three lines:
Read context/ before anything else.
For my voice, read context/voice.md.
For priorities, read context/priorities.md.
It reads this file before every message you send.

Pick a co-founder like a spouse. Onboard your agent like one too: everything, once.
