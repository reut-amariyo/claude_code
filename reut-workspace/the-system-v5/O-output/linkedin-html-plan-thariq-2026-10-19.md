Before this, planning with AI looked like every team I know:
"Make no mistakes" at the end of the prompt.
LGTM on a 600-line plan nobody opened.
"You're absolutely right, sorry for the confusion" at 3 a.m.

Thariq from the Claude Code team stopped writing long plan.md files.
His agent now plans as one interactive HTML page you can read in a minute.

Here's what you get instead of a 600-line plan:

1. 4 sentences you can read in a minute.
"The user can pick a time to send." Not a wall of tech talk.

2. A picture of the screen under each sentence.
You see the button before anyone builds it.

3. Every decision marked in orange.
The questions the agent would have answered alone, waiting for you.

Click once to see the code. Only if you want it.

When you're done, hit Respond and paste the answers back.
The agent keeps asking until the plan is right. Only then it builds.

How to start:
/plugin install html-plan@claude-community
Then type /html-plan and what you want to build.

A plan you can't argue with is a plan nobody reads.
And it's cheaper than the 3 a.m. call.▮
