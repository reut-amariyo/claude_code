## How to Use This File

1. **After sending a pitch:** Add row to "Active Pitches" with date.
2. **After follow-up:** Update Follow-up column + change status to 🟡.
3. **After response:** Move notes to dedicated section, update status.
4. **If booked:** Move to "Booked Interviews" section (create when first one lands).
5. **If declined or 3 follow-ups with no response:** Move to "Closed / Not Active" with reason.
