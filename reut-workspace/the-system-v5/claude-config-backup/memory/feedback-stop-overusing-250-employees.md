Don't drop "250 employees" (or similar team-size stats) into every post. Reut has flagged this twice now as a pattern to stop.

**Why:** It reads as a forced credibility stamp. When the stat appears in posts where team size has nothing to do with the story, it feels like social proof shoehorned in — which dilutes the "real person" voice and reads like humble-brag. Related: Reut already has a rule against defaulting to social proof numbers.

**How to apply:**
- Use "250 employees" ONLY when team size is genuinely central to the point (e.g., posts about management, hiring, scaling operations, macro leadership).
- When the post is about mindset, personal journey, comfort zone, wellness, learning, etc. — do NOT mention team size.
- If Reut's brief doesn't raise team size, don't add it.
- Separate rule still holds: when team size IS mentioned, always say "250 employees," never "100 engineers."
