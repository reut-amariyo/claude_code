# LinkedIn Visuals Library

**Purpose:** The visual decides whether the hook gets read at all. This library tracks what works on the LinkedIn feed scroll.

**How to add:** Auto-populated by `/linkedin-learn`. Visual analysis is done on the actual image/video.

**How to use:** After drafting a post, check this library for visual types that pair well with the structure/topic. Flag to Reut what kind of asset to produce.

## Visual Types

### 1. No Visual (Text-Only)
Pure text posts. Rarer than expected but sometimes outperform when the hook is strong enough.

**When it works:** Ultra-sharp hook, short-punchy structure, topic is divisive/thought-provoking. Also works for dialogue-heavy posts where a visual would distract from the dramatic rhythm.

### 2. Single Static Image — Portrait of Creator
Professional portrait, usually the creator in their environment (office, stage, product).

**When it works:** Personal story posts, milestone announcements, "state of the business" content.

### 3. Single Static Image — Text-on-Image (Quote Card)
Big text quote on branded background. Usually the key line from the post.

**When it works:** Opinion/insight posts. Gives a shareable, screenshot-able moment.

### 4. Single Static Image — Screenshot
Real screenshot of a tool, metric, message, or receipt. Feels authentic and unpolished.

**When it works:** Stat-shock hooks, before/after, build-in-public content.

### 5. Single Static Image — Infographic / Diagram
Clean diagram explaining a framework or process.

**When it works:** Tutorial or framework posts. Reader saves the post.

### 6. Single Static Image — Meme / Humor
Pop culture reference or humorous visual with minimal text.

**When it works:** Observation posts, industry callouts. Risky — must feel native, not forced.

### 7. Carousel (Multi-slide)
3-10 slides. Usually slide 1 = hook, middle slides = content, final slide = CTA or reframe.

**When it works:** Listicle posts, frameworks, step-by-step content. LinkedIn favors carousels heavily in the algo.

### 8. Native Video (Under 90 seconds)
Talking head or screen-recording with captions.

**When it works:** Personal voice, vulnerability, founder stories. High completion rate = high reach.

### 9. Long Video (90s-10min)
Usually repurposed podcast clip or interview.

**When it works:** When the clip has a strong open and the creator has audience authority.

### 10. Photo Carousel (No Text)
Multiple lifestyle/event photos, no overlay text.

**When it works:** Event recaps, team photos, personal milestones.
