Every Lior post (LinkedIn especially) must carry exactly ONE idea. Simple language. One quotable principle that earns the save/bookmark.

**Why:** Reut stated this directly on 2026-05-06. Saves are the highest-intent signal on LinkedIn (mirrors the X bookmark-weighted scoring rule). A post with two ideas dilutes both — the reader can't easily summarize it, so they don't save it. Simple, one-idea posts are screenshot-worthy and shareable.

**How to apply:**
- Before drafting, identify THE ONE principle the post must deliver. Write it as a single sentence.
- Test: can a reader explain the entire post in one sentence after reading? If not, cut.
- Hunt for "secondary ideas" that sneak in (extra benefits, side notes, dual lessons) — kill them.
- One quotable line should anchor the post. Everything else is setup, evidence, or CTA serving that line.
- When a draft has 2+ strong ideas, split into 2 posts instead of bundling.
- Simple language only. If a sentence needs a second read to parse, rewrite.
- Length can run shorter than the 750-char floor for save-optimized posts — clarity beats length.
