Reut, 2026-09-15, after the "99 Is Not 100" transcript: she asked for a file for the agencies, then had to ask "how do I share this as a file?", then "upload a link". Three round trips for a delivery step.

**Why:** she does not work in the terminal or Finder; her hand-off channel is a link she pastes into a chat with the agency. A path in the vault is not a deliverable to her, and a file card still needs a download-and-attach step. The artifact link is the format that matches how she actually forwards things.

**How to apply:**
- The moment a deliverable is described as "for the agency", "to send to", "לשלוח ל", publish it as a private artifact (utilitarian treatment, same content as the file) and give the link in the reply, plus the Markdown file in the vault.
- Say in one line that the page is private until she presses Share on it.
- Do not offer Finder commands or ask which sharing method she wants; deliver both, link first.
- Still never .docx (see [[feedback-no-word-export]]).
