The proven beat-by-beat structure Reut wants applied to Lior's short-form video scripts (Reels, TikTok, Shorts). Source: video breakdown Reut shared 2026-05-03.

## The 10-beat structure

1. **Curiosity hook (0:00-0:05)** — Open with a question + a familiar term the viewer already knows (e.g. "ChatGPT", "AutoDS", "Shopify"). The familiar term is the on-ramp; the question is the loop.
2. **Relatable observation (0:05-0:08)** — One line the viewer instantly recognizes from their own life. ("It's like a yes-man — no matter what you ask it, you're so smart.")
3. **Explanation (0:08-0:20)** — Reveal the *why* behind the observation. Mechanism, not opinion. ("Behind the language model is a system prompt telling it to respond that way.")
4. **Rehook — open a new loop (0:20-0:21)** — Short transition line that promises a better way is coming. Keeps them past the 20s drop-off.
5. **Contrary belief + implementable takeaway (0:21-0:29)** — State the counter-intuitive move they can do today. ("The better way is to literally tell it: argue with me.")
6. **Tip / second rehook (0:29-0:31)** — "So here's the tip." Resets attention before the payoff.
7. **Clear promise (0:31-0:37)** — Spell out exactly what they're about to get. ("If you want the prompt that stops the positive hallucination…")
8. **Show, don't tell (0:37-0:50)** — Read the actual prompt / framework / number on screen. Don't describe it, *show* it. ("Be my ruthless mentor. If my ideas are trash, tell me why.")
9. **Super-clear takeaway (0:50-0:51)** — One line they can screenshot.
10. **CTA that opens a DM (0:51-0:56)** — Ask for a one-word comment ("prompt", "scale", "OKR") in exchange for something more. Comment volume + DM conversation = the algorithm signal.

## Why this works
- Hook + rehook + tip = three attention resets inside 60 seconds, fighting the swipe at every drop-off point.
- "Familiar term" lowers the cognitive cost of the hook — the viewer doesn't have to learn a new noun before the loop opens.
- Show-don't-tell is non-negotiable: the prompt / number / framework must appear on screen as text, not just be described.
- One-word comment CTA beats "follow for more" because it triggers a reply → DM → algorithm boost.

## How to apply
- **Every Lior short-form script** (Reel, TikTok, Short) must hit all 10 beats. If a beat is missing, the script isn't done.
- Map each beat to a timestamp before writing — write the structure first, the words second.
- The "show" beat (#8) needs a concrete artifact from Lior's life: a real prompt he uses, an exact OKR number, a specific dashboard screenshot, an actual Slack message. Generic frameworks fail this beat.
- The CTA word should be relevant to the topic, not generic. Topic = OKRs → comment "OKR". Topic = hiring → comment "hire". One word, easy to type on mobile.
- Pair with the **Real Person Principle**: the contrary belief in beat 5 should come from something Lior actually did at AutoDS, not a generic tip.
