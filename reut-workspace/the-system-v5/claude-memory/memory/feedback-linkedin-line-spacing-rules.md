Reut asked 2026-09-29 (Anthropic IPO post) that I learn post STRUCTURE: where the blank line goes, where a sentence gets cut. She could not see my spacing in rendered markdown.

**Delivery rule:** give LinkedIn drafts inside a ``` code block so every blank line is visible and copyable (supersedes plain-text delivery for full posts; replies/comments stay plain).

**Spacing rules** (from Reut's locked Codex post 2026-09-07 + Justin Welsh, Sahil Bloom, Tom Orbach, Codie Sanchez top posts):
1. Blank line = new beat. One thought per block.
2. STACK lines with no blank between them when they are one unit: a list, a parallel rhythm set ("Maybe your spouse. / Maybe your friends."), a two-line couplet close ("Claude is not dead. / It has a colleague."), or a 2-step mini story (event / "3 weeks later...").
3. Punch lines stand alone with air on both sides: "2 customers." "Good." "Sure."
4. A colon line sets up a reveal; the reveal gets its own block ("The crazy part:" / blank / reveal).
5. Hook, blank line, line-2 parenthetical (Codex post, Sahil).
6. Numbered item: title line, blank, body (Reut's Codex spacing). Keep items the same length.
7. No line over ~20 words. Split a long line at its natural turn (", and", "3 weeks later") into two stacked lines, or cut it.
8. Rhythm target: short, short, one denser stacked block in the middle, short close. Reut deliberately kept a 5-line unbroken middle block in the Codex post — do not re-space her grouping.

**Data check:** in 1,684 swipe posts, over- vs under-performers per creator had the same spacing (lines per block 1.09 vs 1.11). Spacing is a readability craft, not an algorithm lever; follow Reut's eye.

**How to apply:** before delivering any Lior post, run these 8 rules and ship in a code block. Related: [[linkedin-posting-rules]], [[reference-tom-orbach-humor-playbook]], [[feedback-never-revert-to-my-earlier-draft]].
