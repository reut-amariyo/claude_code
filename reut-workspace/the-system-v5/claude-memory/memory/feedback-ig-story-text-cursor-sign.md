Reut, 2026-08-25: whenever she asks for Instagram story text (any slide, any language),
always end the text with the full block cursor `█`. Applies to every story draft I hand her,
including short one-line slides and bullet lists.

**Why:** the cursor is part of the story's visual style on Lior's account, it makes the
overlay text read as live typing. She does not want to add it manually every time.

**How to apply:** append `█` at the end of the last line of each story slide draft. Never `|` or `▌`.
Only for IG stories, not for posts, replies or comments. Related:
[[feedback-post-draft-delimiters]], [[feedback-reply-formatting]].
