Reut, 2026-08-25: whenever she asks for Instagram story text (any slide, any language),
always end the text with the full block cursor `█`. Applies to every story draft I hand her,
including short one-line slides and bullet lists.

Reut, 2026-09-24: extended to LinkedIn. Every LinkedIn post draft ends with `█` as the very
last character, after the CTA / hashtags line, inside the "--- POST ENDS ---" fence.

Reut, 2026-09-24, later the same day: the cursor is now `▮`, not `█`. Use `▮` everywhere
the old `█` rule applied.

**Why:** the cursor is part of Lior's visual style, it makes the text read as live typing.
She does not want to add it manually every time.

**How to apply:** append `▮` at the end of the last line of each IG story slide and each
LinkedIn post draft. Never `█`, `|` or `▌`. NOT for LinkedIn comments, X posts, X/LinkedIn replies
or DMs unless she asks. Related: [[feedback-post-draft-delimiters]], [[feedback-reply-formatting]].
