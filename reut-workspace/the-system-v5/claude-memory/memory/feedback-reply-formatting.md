---
name: Reply copy-paste formatting
description: When presenting X/Twitter reply drafts, format them as easy-to-copy plain text blocks, not inside markdown blockquotes
type: feedback
---

Always present X/Twitter reply drafts as plain text that's easy to copy-paste - not inside markdown blockquotes (> prefix) or other formatting that makes copying harder.
**Why:** User needs to quickly copy replies and paste them into X. Blockquotes add ">" characters when copied.
**How to apply:** Use a simple code block or plain text section for each reply draft so the user can copy it cleanly with one click.
