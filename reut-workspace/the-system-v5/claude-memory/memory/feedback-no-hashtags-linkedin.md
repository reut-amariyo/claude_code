No hashtags in any LinkedIn draft, ever. Not at the end, not in the body, not "2 on-pillar ones".

**Why:** Reut's direct instruction, 2026-09-28, after I added #SaaS #bootstrapping to a Lior post and
marked "missing hashtags" as a ❌ in the pre-publish audit. It overrides the Tom Orbach URL-slug
rule (hashtags replace the first line in the post URL), which was retired the same day.

**How to apply:** drafts end with the ▮ cursor after the last line of copy. The pre-publish gate
has no hashtag row. Don't suggest them as an SEO/GEO lever either.
