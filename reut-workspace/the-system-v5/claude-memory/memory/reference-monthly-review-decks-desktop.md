Lior's monthly performance review decks are stored at:

    ~/Desktop/brand/month sum/

As of 2026-08-19 it holds `Lior-Pozin-May-2026.html/.pdf/.pptx`,
`Lior-Pozin-July-2026-Review.pdf`, and `Lior-Pozin-Q1-2026.pptx`.

**Why this matters:** the vault only contains `O-output/monthly-summary-2026-06/` and
`-2026-07/`. May 2026 is NOT in the vault, so a vault-only search concludes the month was
never captured. It was. The May deck carries full per-platform numbers, including the
Instagram figures the Q2 review could only give as a 90-day aggregate
(May IG: 3.5M views, 38,137 profile visits, 65,876 followers, +3,163 net).

The HTML version is the readable one - it is a self-contained slide deck, so reading the
file gives every number without rendering it.

**Rule: check this folder before reporting any month's data as unavailable.**
