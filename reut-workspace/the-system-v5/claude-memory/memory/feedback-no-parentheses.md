Never use parentheses in any content draft (posts, replies, comments, scripts, hooks). Reut doesn't like them.

**ONE sanctioned exception (Reut, 2026-08-12): the line-2 parenthetical counter-hook.** A short parenthetical sentence as line 2 of a hook that reverses or undercuts line 1, e.g. line 1 "Reacting fast feels productive." line 2 "(It's usually destructive.)". Reut flagged this on a Sahil Bloom post and confirmed it catches attention; he uses it in 3 of 3 harvested posts. Constraints: hook position only (line 2), one sentence under 6 words, must flip line 1, max once per post. Full teardown in the-system-v5/O-output/linkedin-viral-harvest/structure-harvest-2026-08-05.md, Post #11.

**Why:** Parentheses usually hold something that either doesn't add to the text or, if it's actually important, shouldn't be sidelined in brackets. They read as an aside the eye skips, which weakens the line. In the hook exception the aside-reading is the point: the whisper lowers the reader's guard right before the reversal lands.

**How to apply:** If the parenthetical content is non-essential, delete it. If it's important, fold it directly into the sentence as a main clause. Applies across all platforms and languages. Pairs with [[feedback-anti-ai-writing-rules]].
