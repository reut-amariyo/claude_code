Every Lior X post must map to ONE of three archetypes, weighted weekly. Trying to be all four dilutes the account into noise.

- **Primary (70%) — The Operator:** CEO perspective from inside a 250-person SaaS. What's working, what's broken, what we just changed, what we just killed. BTS of running the company.
- **Secondary (20%) — The Builder:** Numbers, wins, losses, building-in-public moments. Specific revenue/ops/team milestones.
- **Tertiary (10% MAX) — The Contrarian:** Hot takes / real opinions on SaaS, AI tools, founder culture. Use sparingly — Lior's edge is operator credibility, not provocation.
- **DO NOT use — The Educator:** Frameworks, "5 lessons I learned," teaching/breakdown posts. Not Lior's lane. Reads as generic LinkedIn content recycled to X.

**Why:** Stolen from Wiz of Ecom's 30-founder agency system (2026-05-01 thread, 147K views). Pick one archetype, double down, and the algo + audience learn what you stand for. Diluting across all four = no recognizable voice.

**How to apply:**
- Before scout-day generates 5 posts, check the weekly mix matches: ~3-4 Operator, ~1 Builder, 0-1 Contrarian, 0 Educator.
- If a draft starts with "Here are 5 things I learned..." or "The framework for X..." — kill it. Wrong archetype.
- When unsure between angles, default to Operator (CEO POV from inside the building).
