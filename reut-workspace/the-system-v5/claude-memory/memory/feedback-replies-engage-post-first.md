When drafting a reply/comment to someone's post, the first job is to respond to the post's actual content — extend the idea, add an operator's angle, answer what was raised. A real Lior story with a specific number is the preferred vehicle WHEN it fits naturally, but forcing one in reads as self-promotion and ignores the author.

**Why:** Reut rejected a reply to a Sahil Bloom mindset post (2026-08-03) that pivoted straight into the eBay-block origin story: "לא בכל תגובה צריך לדחוף בכח את הסיפור של ליאור. צריך להתייחס למה שנכתב בפוסט." This refines the older "every reply must include a story" rule and extends [[feedback-comment-answer-the-question]] beyond direct questions.

**How to apply:** Start from the post's core idea and ask what Lior would genuinely add to it. If a story earns its place as proof of that addition, use it. If the post is a mindset/principle post, a sharp operator take that extends the author's point beats a biographical anecdote. Still follow [[feedback-reply-voice]], [[feedback-linkedin-comments-keep-short]], and the anti-AI rules.
