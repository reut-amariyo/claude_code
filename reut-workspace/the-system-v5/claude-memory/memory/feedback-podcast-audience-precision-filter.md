Lior declined an interview on Popcorn (פופקורן, Lior Frenkel's podcast) on 2026-08-09. The reason was language: it is a Hebrew podcast. Lior's podcast appearances serve his English-speaking, US-first brand.

Correction 2026-11-18 by Reut: an earlier version of this memory said he declined because the audience was "too mainstream". That was wrong. Do not use Popcorn as evidence that Lior rejects broad or career-oriented entrepreneur audiences.

**Why:** the brand targets US/English audiences; Hebrew shows don't move that.
**How to apply:** add a language filter to [[feedback-podcast-vetting-checklist]]: Hebrew-language podcasts are a default no unless Reut asks. Audience fit for English shows is judged on its own merits, not by the Popcorn precedent.
