2026-09-10. Asked for 3 posts "on the same structure as the 25K Claude→Codex post", I delivered
drafts that reused its content: the "9 months" number, the Claude-vs-Codex frame, "I know. You X.
So did I.", "Here's how to...", and a "last week I posted" callback. Reut: "אני לא מבינה למה אתה
מעתיק כל כך את הפוסט הקודם. התכוונתי במבנה... אי אפשר להשתמש באותו הוק. אני רוצה לשחזר את המבנה
לא להעתיק את התוכן."

**Why:** the audience saw the original two days ago. A recognisable hook or line reads as a rerun,
and reruns get the copy-paste penalty we already measured (693 imp on a republished winner, see
[[lior-post-fiverr-anniversary-3-choices]]).

**How to apply:** when a proven post is the donor, copy only the beat functions: hook shape, counter-
hook slot, permission line, confession, trigger, named cost, N steps, close that refuses the verdict.
Every wording is new: new anchor number, new permission sentence, new confession, new transition into
the steps, no reference to the earlier post. Test: put the two posts side by side, no sentence may
rhyme. Related: [[feedback-vary-post-openings]], [[feedback-build-on-proven-structures]],
[[lior-post-claude-to-codex-migration]].
