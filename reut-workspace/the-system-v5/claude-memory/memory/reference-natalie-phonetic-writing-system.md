When Reut says "write like Natalie" (Lior's English teacher), produce normal readable English with a **phonetic respelling layer** on top so Lior reads with a native American accent. Reut has asked for this format multiple times — reproduce it without re-asking.

**Two layers over the base English text:**
1. Parenthetical pronunciation guide after hard/long words: `word (PHONETIC)`.
2. Inline respelling inside the word itself for open-A sounds and reductions.

**Rules:**
- Stressed syllable = ALL CAPS; syllables separated by hyphens → `KUM-puh-nee`, `in-VES-t'rz`, `duh-REK-sh'n`
- Schwa / unstressed vowel → "uh", or dropped to an apostrophe → `foun-d'r`, `num-b'r`, `fo-k's`, `me-th'd`, `c'm-PLEET`, `t'` (=to), `'n` (=and)
- Open ah/o vowel (top, dollar, not, talk, start, all, market) → **AA** → `tAAp`, `dAAl'r`, `nAAt`, `TAAKS`, `STAArt`, `mAArket`, `AAll`
- Long A (name, changed, -tion) → **AY** → `chAYnjed`, `mou-duh-VAY-sh'n`
- Rounded ow/oh (founder, those, focus) → **OW** → `FOWN-d'r`, `thOWz`, `FOW-k's`
- Long I → **Y** → `s'r-VYVE`, `k'm-PYLD`
- Long U → **oo / yoo** → `c'n-TIN-yoo`
- Suffix -y → **-ee** → `KUM-puh-nee`, `KUM-puh-neez`
- American T-flap: intervocalic t → d → motivation = `mou-duh-VAY-sh'n`
- Function-word reductions: and→`'n`, to→`t'`, for→`f'r`, of→`'v`
- Emphasize hard consonants by capitalizing: `someTHing` (reminds him of the th)
- -tion→`-sh'n`, -er/-or/-ar→`-'r`, com/con/cer→`c'm/c'n/s'r`

Base text rules still apply (English only, anti-AI voice, etc.) — this is purely a pronunciation overlay on already-approved copy. Related: [[feedback-posts-always-english]], [[lior-pozin-os]].
