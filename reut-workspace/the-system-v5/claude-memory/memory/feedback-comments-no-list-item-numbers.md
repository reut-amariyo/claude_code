Never open or anchor a Lior comment on a list post with the item number ("#5 did the most for me", "#3 is where most people break").

**Why:** Reut 2026-09-29: pointing at a specific numbered item reads very AI.

**How to apply:** Engage the idea itself in Lior's own words, as if he's reacting to the thought, not grading the list. Related: [[feedback-linkedin-comments-keep-short]], [[feedback-anti-ai-writing-rules]].
