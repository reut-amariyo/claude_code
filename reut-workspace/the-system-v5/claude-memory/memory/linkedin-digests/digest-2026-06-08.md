## 🧩 Patterns That Worked This Week

1. **Market-empathy + hiring-as-gift is the cross-creator breakout (n=2 confirmed).** Bartlett's "laid off? we're hiring" = his #1 (4,202 / 259 reposts); Lior's Tough-days in the same lane = ✅⭐ (14,798 / 15 reposts). Two different creators, same lane, same week, both top-of-profile. The ingredients that make it travel: **(a) name the specific casualty, (b) make a concrete help/hiring offer, (c) let the comment thread route people.** Lior's 34,454-layoffs post proved the inverse — same topic minus those ingredients = 🟡 cap.
2. **One-word / caption-only CTAs win reach when the visual carries the claim.** Hormozi "Agree?" (4,753 & 2,971), Dan Koe "Just one hour. Please." (2,541), and Lior's "900 prompts" (5,008) all put the payoff in the image and used a curiosity/agree gap as the entire caption. Reach-maximizing, comment-suppressing.
3. **Question + command hooks own comment density.** Welsh's "Forget being worth $100M. What's the point?" (740 comments) and "cheat code is hard work" (714). When the goal is dialogue, a contrarian question beats a story.
4. **Aphoristic parallel-list hooks remain a reliable 1,500–2,500 floor.** Hormozi "Rich people buy time…", Koe's micro-hook. Rhythm + screenshotability; the structure is the hook.
5. **Text-first / visual-carried-claim continues — carousels absent from the top 10 for the 5th straight scanned week.** When the take or the visual punchline is sharp, a multi-slide carousel only dilutes it.
