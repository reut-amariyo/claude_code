Never mention Shopify as a potential buyer/acquirer for AutoDS in any content.

**Why:** Shopify is a key partner (AutoDS is #1 Shopify partner/affiliate). Framing them as a "could have been buyer" is sensitive and not something Lior wants public. This extends the existing rule of never criticizing Shopify - also don't position them in acquisition narratives.

**How to apply:** When writing about mapping potential buyers or acquisition stories, use generic examples ("direct competitors", "complementary platforms") instead of naming Shopify specifically.
