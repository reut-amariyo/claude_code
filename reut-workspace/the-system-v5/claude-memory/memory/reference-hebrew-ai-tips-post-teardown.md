## Structural skeleton (10 beats)
1. **Authority newsjack hook.** "Anthropic published a guide" — a big-company news event opens, the author rides it. Credibility is borrowed, then personalized.
2. **Free-bonus line.** "הוספתי לכם גם בונוס בחינם" — generosity signal in line 3.
3. **Practitioner frame.** "איך אני משתמש בו בתאכלס" — I actually use this, not theory.
4. **Audience widening + objection pre-kill.** "רק למפתחים? ממש לא!" — kills the "not for me" scroll-away in one line.
5. **Save CTA with an implementation appointment.** "תשמרו את הפוסט וחצי שעה לנסות מחר בבוקר" — not just "save this" but a scheduled half hour tomorrow morning. Converts a save into a plan.
6. **Hierarchy: tip #1 elevated above the list.** The most important idea gets its own section before the checklist starts (important task vs. hard task distinction).
7. **Checklist of copy-paste artifacts.** ☑ items where the value is literal prompt snippets in quotes the reader pastes verbatim. The post is a TOOL, not content — this forces the save because the exact wording is the value.
8. **Simple mental model / analogy.** "The tool is an employee: model = education level, thinking effort = how much work you ask for." One-line teachable analogy.
9. **Cross-model generalization.** "Works with GPT Sol too" — widens from Claude users to everyone doing serious AI work.
10. **Activation protocol + report-back loop.** 3 steps: pick a task you've been postponing → paste the above → "ספרו לי איך זה עבד". The report-back request manufactures future comments. Close: share CTA + "what golden tip of yours works great?" — an expert-positioning question (commenters contribute, not vent).

## Psychological engine
**Immediate utility.** The reader leaves with artifacts, an appointment, and a reason to come back and comment. Saves come from copy-paste value; comments come from the report-back loop and the expert-positioning question.

## New moves worth stealing (beyond Reut's existing formula)
- Implementation appointment attached to the save CTA ("half an hour tomorrow morning").
- Copy-paste prompt snippets as the checklist items — artifact posts outperform advice posts on saves.
- Report-back loop ("tell me how it went") as a delayed comment engine.
- Expert-positioning close question instead of a venting/opinion question.
- Elevating THE one tip above the list before the checklist body.
