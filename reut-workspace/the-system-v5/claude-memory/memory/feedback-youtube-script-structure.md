Reut's rule (2026-07-12) for ALL YouTube scripts, in this order:

1. **Answer the "what" first.** Open by telling the viewer what this video is about / what they're getting. No slow warm-ups.
2. **Then hit the viewer's pain point.** Right after the "what", name the pain the viewer feels so they know this video is for them.
3. **Open a loop, and close it relatively fast.** Tease what's coming, but deliver at least the FIRST point quickly. Don't stack unresolved loops early — viewers leave if the payoff is delayed.

**Why:** YouTube retention drops in the first seconds. Clarity ("what") earns the click's promise, pain creates relevance, and an early payoff builds trust to keep watching the rest.

**How to apply:** Structure every YouTube script draft as: WHAT → PAIN → LOOP OPEN → first point delivered early (loop partially closed) → remaining points. All the usual voice rules still apply ([[feedback-anti-ai-writing-rules]], [[lior-brand-pillars-2026]] when the script is for Lior).
