# Lior never talks about token savings

**Rule:** In every Lior post that mentions AI tools, cost, or model selection — **NEVER frame around token/dollar savings.** ALWAYS frame around:
- Work efficiency (time to ship, hours reclaimed)
- Output volume (more decisions, more features, more analyses)
- Quality-at-speed (good enough + fast > perfect + slow)
- What the reclaimed time enables (better decisions, faster iteration, higher-value work)

**Why:** Talking about token costs positions Lior as a **techie hobbyist** counting cents. Talking about work efficiency positions him as a **CEO scaling a 250-person operation.** Lior's brand is the operator who ships. His audience (founders, executives) cares about output, not infrastructure bills.

**Concrete translation:**

| ❌ Never write | ✅ Rewrite as |
|---|---|
| "$4,200 in tokens" | "3 hours became 20 minutes" |
| "Cheaper model" | "Faster model" or "Right-sized model" |
| "Token-saver" | "Time-saver" |
| "Pay per token" | (skip entirely; not his lane) |
| "Wasted tokens" | "Wasted hours" or "Weekends I lost" |
| "AI bill" | "Timeline slipping" |
| "Cost-optimized" | "Output-optimized" |
| "Save money on AI" | "Ship more with the same team" |

**Where this hits hardest:**
- Any post about Claude/OpenAI/Anthropic model selection
- Any post about AI stack or tooling
- Any post about AI ROI (frame as time/output ROI, never cost ROI)
- Any post about "which tool to use when"

**Exception — none.** Even if the entire topic is about pricing changes (e.g., Anthropic launches per-token billing), Lior's angle is: "What this means for how we ship" — not "how much we save."

**Context:** Reut established this 2026-05-XX when reviewing a draft about Fable 5 that led with "$4,200 in tokens." Cost framing broke the CEO voice. Rewrote around Saturday-night board deck example: efficiency and time-to-ship.
