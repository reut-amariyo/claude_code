Post: "These are the exact Claude Skills I use every day." 3 skills (/grill-me, /handoff by Matt
Pocock, /big-three by Lior), page follow.liorpozin.com/skills, visual = polished animated flow GIF
(cream, serif headline, pixel robots, Claude spark) modeled on a Ruben Hassid how-to-ai.guide card.
Result at 15h: 688 impressions, 480 members reached, 50% in-network / 50% out-of-network,
4 profile viewers, 0 followers. Not suppressed (half the reach was out-of-network, so LinkedIn
did test it on strangers); it failed the test. Reut: not AI-slop, it simply didn't work. See [[project-lior-claude-skills-giveaway]].

**Reut's lesson (2026-10-14): graphics that are too "pretty" don't work on Lior's account.**
Matches [[feedback-linkedin-visual-one-artifact-not-diagram]] (Astra flowchart) and the
"never marketing-team graphics" rule. I built it anyway after flagging it once.

Other causes, all already in the rules:
1. Hook was Ruben's opening line almost verbatim; no number, no credential, no Lior anchor.
2. Topic gate fail: 2 of 3 skills were someone else's = generic curation = 0 followers.
3. The confession/trigger beat (mentor story) was cut, so it read as a tool tip, see
   [[feedback-howto-beats-are-structural-two-flops]].
4. Stack contradiction: a month earlier he posted "Moved to Codex in 4 min"; the-system-v5
   CLAUDE.md says his stack is Hermes + Codex. "Claude Skills I use every day" undercuts that.
5. AI how-tos hit 1 in 5 on this account; this one had no news "why now".

**How to apply:** for Lior, the visual is a raw artifact (real screenshot, real photo), never a
designed infographic, even when a creator's designed card is the reference. If Reut asks for a
designed card, say once that this post is the counter-example, then follow her call.
