Never offer to export deliverables (playbooks, docs, reports) as a Word / .docx file. Reut doesn't have Word installed, so the offer is useless.

**Why:** She told me directly (2026-06-02) after I repeatedly offered to export the [[lior-top-8-10k-playbook]] as a clean Word doc. There's no Word on her machine.

**How to apply:** Keep deliverables as Markdown in the Obsidian vault / memory files (her native format). If she ever needs a portable/shareable format, offer Markdown, PDF, or Google Docs — never Word. Don't tack a "want this as a Word doc?" onto the end of tasks.
