When a post asks a direct discussion question (e.g. "Do you agree?", "What would you do?"), the comment should answer that question genuinely. Do NOT shoehorn a Lior story in.

**Why:** Reut rejected a $1-bug-story comment on Rob Dance's "hard times test you" post. She said the post asks "Do you agree?" so the reply should answer it, not hijack the thread with Lior's incident. Forcing a story onto a simple question-post reads as self-promotion, not engagement.

**How to apply:** Before drafting any comment, check whether the post ends with / centers on a direct question. If yes, lead with a genuine answer ("Agreed.", "Mostly, but...") plus one sharp real-perspective line. Story-anchoring (specific number/client/moment) is for original posts and for comments where a story actually adds proof, NOT for every comment. This nuances the older blanket rule "every reply/comment MUST include a real Lior story." Still keep comments tight (2-4 short lines per [[feedback-linkedin-comments-keep-short]]) and apply [[feedback-anti-ai-writing-rules]].
