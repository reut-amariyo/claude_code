Reut, 2026-09-13, on the "Ok GPT-6 Astra is a BEAST" post: it did not succeed, the graphic was too much,
keep it simpler. Full teardown: the-system-v5/M-memory/linkedin-astra-cofounder-teardown-2026-09-13.md

**Why:** the shipped GIF was a 10-box flowchart that restated the copy's 3 steps and the full prompt in
small type. It added zero information, was unreadable on mobile, and frame 1 equalled the last frame so the
animation had no reveal. The 25K winner 3 days earlier ([[lior-post-claude-to-codex-migration]]) showed
two big numbers the text did not contain. Every draft version had planned "real AGENTS.md screenshot,
one line circled red" and the infographic replaced it at the end.

Second cause: the 8-beat how-to template was the plan, but v17 and v18 trims removed the confession,
permission line, trigger and cost beats. Only the 3 steps and the close survived. Without the
Lior-specific beats the post was a generic tool tip with a hype hook ("Ok X is a BEAST" + "until I
tried this:"), the lane [[feedback-no-productivity-tool-tips]] says we lose.

**How to apply:**
- The LinkedIn visual is ONE real artifact or ONE big number. Never the post redrawn as a diagram, never a
  flowchart, never the steps repeated in the image. If the image says nothing the copy does not, cut it.
- A GIF must change between frame 1 and the last frame, or ship a still.
- Re-run the beat table on the version that ships, not the version that was approved. A trim that deletes
  a beat is a structural edit and needs the gate again.
- A how-to only earns its exception with the confession and permission beats present. Cutting them
  turns it back into a tool tip.
