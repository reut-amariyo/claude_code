Never open a comment or reply draft with "[Name]," or any bracketed name placeholder. Deliver the reply ready to paste as-is.

**Why:** Reut said so explicitly on 2026-10-11 ("לא צריך אף פעם שתכתוב שם בסוגריים"). She tags/handles names herself on LinkedIn; the placeholder is just friction.

**How to apply:** Write replies without a name slot. If the commenter's real name is known, Reut decides whether to tag; otherwise just start with the reply itself. Overrides the "credit the commenter by name first" habit from [[feedback-lift-up-commenters]] when the name isn't given.
