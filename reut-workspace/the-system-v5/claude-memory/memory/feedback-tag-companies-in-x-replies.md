When drafting a Lior reply on X and a company is named — AutoDS or any other (Fiverr, Shopify, etc.) — prefix the company name with `@` to tag/mention the company's X account. E.g. write `@AutoDS`, `@fiverr`.

**Why:** Reut wants companies tagged in replies so the mention reaches/credits the actual brand account, not just plain text.

**How to apply:** Add `@` before the company name in the reply body. Use the EXACT correct handle — a wrong handle tags an empty/wrong account and looks sloppy. If unsure of a handle, flag it to Reut before posting rather than guessing. Confirmed handles: AutoDS → @AutoDS (verified by Reut 2026-06-09). Likely (verify if unsure): Fiverr → @fiverr, Shopify → @Shopify. Relates to [[feedback-reply-voice]] and [[feedback-reply-formatting]].
