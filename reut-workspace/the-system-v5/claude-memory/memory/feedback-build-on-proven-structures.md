Reut, 2026-08-30: "מעכשיו אני רוצה לבנות פוסטים ללינקדין רק על גבי מבנים שהצליחו לאחרים."
Every Lior LinkedIn post now starts from a donor post that already performed for someone
else. She supplies the donor, or I find one. The structure is copied beat by beat, the
content is 100% Lior.

**Why:** inventing a structure per post is where the drafts go flat. A post with 1,000+
reactions has already proven its skeleton against the algorithm and the audience, so the
only open variable left is whether the content is good.

**How to apply:**
- Map the donor first, as a beat table: hook shape, counter-hook, stat placement, item
  count, item shape, close, CTA, visual type. Put the table in the output file above the
  draft so Reut can see what was borrowed.
- Strip the donor's AI tells. Most high-performing CEO posts run on "X, not Y" in every
  line, which is the exact shape LinkedIn's slop report flags. Rewrite each one.
  See [[linkedin-ai-slop-penalty]] and [[feedback-anti-ai-writing-rules]].
- Copy the donor's visual FAMILY, not just its text. Partaker's 7-truths post won on a
  photographed physical artifact, a real book page with highlighter. The Lior equivalent
  is a real photo of his phone or notebook, shot not designed.
- Length rules bend to the donor. A numbered list post runs ~1,700 chars and that is fine;
  the 750-1,200 rule is for narrative posts.
- Still applies on top: [[feedback-diversify-inspiration-creators]] Ruben Hassid moratorium,
  and [[feedback-linkedin-kpi-followers-not-impressions]] every post answers "why follow?".
