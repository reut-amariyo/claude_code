# LinkedIn post URL: hashtags override the first line

**Source:** Tom Orbach, Marketing Ideas newsletter, 2026-08-24 (paid issue). Example cited:
SEO consultant Chris Long posted with #bananalife #spongebob and the post URL came out
`linkedin.com/posts/...bananalife-spongebob`. Not independently verified by us; cheap to test.

**The mechanic:** LinkedIn generates every post's permanent URL slug from the post's FIRST LINE.
A hook like "so I was thinking this morning" becomes that post's address forever. If the post
carries hashtags, LinkedIn uses the hashtags in the slug instead of the first line.

**Why it matters for Lior:** LinkedIn posts rank in Google, and AI answer engines read Google.
The URL is one signal machines use to decide what a page is about. It costs 3 seconds per post
and it is the only part of the slug we control. Small lever, but it stacks with the ALT-text
rule in [[linkedin-posting-rules]] and the entity/topic logic in [[geo-veeda-principles]].
It also feeds the same topic-classification surface described in [[linkedin-interest-graph-2026]].

**How to apply:** Put exactly 2 hashtags at the end of every Lior LinkedIn post, naming what the
post is actually ABOUT in searchable terms, not mood tags.
- ❌ #mondaymotivation #hustle #founderlife
- ✅ #ecommerceautomation #aiagents / #saaspricing #pricingstrategy / #dropshipping #shopify
Keep them on-pillar so the slug reinforces the same topics the interest graph is already
classifying him under. Two only, lowercase, no hashtag stuffing inside the body.
