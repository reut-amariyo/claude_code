Since 2026-09-29 Reut sends a Plaud share link after every meeting with Lior (web.plaud.ai/s/pub_...). Goal: learn Lior's and Reut's voice, track what was agreed, mine stories.

**How to apply:** open the link in the built-in browser, click the "Transcript" tab, read `document.body.innerText`. The share page wraps an iframe, so use the /nshare3/ URL directly. Save one processed note per meeting to `the-system-v5/B-brain/meetings/YYYY-MM-DD-topic.md` with decisions / open threads / tasks / story material / voice notes. That folder is gitignored because it holds budgets and negotiations. Stories go to the book source bank too ([[project-lior-book-bestseller]]). Hebrew transcripts are low quality and speakers come unnamed, so mark quotes as paraphrase and attribute by content.
