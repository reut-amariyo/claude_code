When Reut asks to draft a LinkedIn comment/reply, default to ONE short cutting line. Two lines is the ceiling; never a mini-post.

**Why:** Escalating feedback. First (May 2026): "always phrase shorter when I ask for LinkedIn comments," 2-4 lines max. Then on 2026-08-12 I delivered a 3-line comment for a Sahil Bloom post and she posted only the closer: "Ship fast, react slow (:" — she cut everything except the quotable. Her words: "אני רוצה דברים קצרים וחותכים" (I want things short and cutting). Long comments read like a hijack of someone else's post.

**How to apply:** Draft the comment as if only the best line survives, because it will. Find the one quotable, aphoristic line and deliver THAT as the comment. Setup lines, context, and story beats get cut unless a story is explicitly wanted. If a proof number fits inside the one line, great; otherwise skip it. Offer a slightly longer variant only as a secondary option, never as the main draft. Pairs with [[feedback-replies-engage-post-first]] — the one line still has to respond to what the post actually says.
