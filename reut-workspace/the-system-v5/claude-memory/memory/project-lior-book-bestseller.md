Started 2026-08-12. Reut wants a book that becomes an Amazon bestseller, Claude as
Lior's ghostwriter. Theme space: dealing with "no" / bootstrapping without
investors — likely one merged book (the bootstrap story IS a story of hearing no;
working thesis: process every no with the "Okay, and then what?" chain).

**Workspace:** `the-system-v5/O-output/lior-book/` — book-concept.md (thesis,
title directions, open questions) + source-bank.md (the collection log).

**STANDING ORDER for every session:** any recording Reut sends, any new podcast
appearance, any unscripted Lior material = candidate book material. Mine it for
[NO] / [BOOT] / [FRAME] / [STORY] / [QUOTE] entries and log in source-bank.md.
Verbatim quotes beat paraphrase — his spoken sentences are the book's voice
([[lior-spoken-voice-dna-e97]] is ground truth).

Collection phase only; no chapters drafted yet. All brand guardrails apply
([[lior-brand-pillars-2026]], [[feedback-anti-ai-writing-rules]]). Reut is the
final gate; nothing goes to Lior or Amazon without her.

**Why:** an audio-first, dyslexic author means the book gets built from
recordings, not from him writing. Every unscripted source is scarce and precious.

**How to apply:** when transcribing/analyzing any Lior audio for other purposes,
ALSO harvest for the book in the same pass and append to source-bank.md.
