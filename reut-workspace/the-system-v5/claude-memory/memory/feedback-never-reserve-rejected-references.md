On 2026-09-21 I sent a 7-topic swipe list; Reut answered "אין פה דברים רלוונטיים". In the next list I
re-included Vin Vashishta (item 4 of the rejected list) because it still met the likes floor. Reut:
"אל תבביא לי דברים שכבר פסלתי!"

**Why:** a wholesale rejection covers every item, not only the ones she named. Re-serving one reads as
not listening, and it costs her a review cycle.

**How to apply:** keep a per-session "rejected" set of post URLs and creators. Before sending any list,
drop everything in it. If nothing new is left, say "nothing new that passes" and propose how to widen
the pool, never pad with a rejected item. Rejected 2026-09-21: Rauch (AI hardest work), Hala Taha
(Gary Vee headcount), Gary Vee (all), Codie Sanchez (culture + Necker), Vashishta (SaaS vendor steps),
Roetzer (NYC schools), Stebbings (grandparents). Related: [[feedback-swipe-reference-bar]],
