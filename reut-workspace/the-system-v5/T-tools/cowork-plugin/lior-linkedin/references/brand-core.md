## The tutorial exception

A how-to is allowed ONLY when all three are true: framed as insider intel from an authority
Lior stress-tested himself, opened with an operator confession, and closed on a strategic or
human insight. A plain "here's how to use [tool]" with none of those is banned.

Evidence: the 93K MD-to-HTML post cleared ~93,000 impressions this way. Note it converted at
0.09% engagement, the lowest of any winning post, so it is a reach lever, not an affinity one.
